# Ritmo

Aplicativo Flutter de gestão de estudos, revisão espaçada e Pomodoro, desenvolvido em dupla para a disciplina de Desenvolvimento para Dispositivos Móveis da UFRN.

Projeto em fase inicial, com configuração básica do Flutter e uma tela provisória. As funcionalidades serão desenvolvidas seguindo a arquitetura MVVM.

As referências visuais estão na pasta `style/`.
